## 1. Огляд гри

**Escape from Hell** — одиночний 2D платформер де гравець керує колишнім священиком Данилом, який спускається крізь 10 кіл пекла щоб врятувати 100 душ що потрапили туди помилково.

### Ключові особливості
- 100 рівнів в 10 колах пекла
- 100 іменних душ з унікальними історіями + 20 прихованих
- Уникання ворогів замість бою (посох лише відштовхує)
- Система гріху що впливає на кінцівку
- 6 різних кінцівок залежно від дій гравця
- Гібридна генерація рівнів (статичні + процедурні)
- Адаптивна музика з шарами
- Android з банерною рекламою та опцією "Без реклами"

## 2. Історія та персонаж

### Данило — колишній священик
Колишній священик що втратив віру. Помер і потрапив між небом і пеклом. Бог дає йому завдання: врятувати 100 душ що опинились у пеклі через бюрократичну помилку.

Щоб вижити в пеклі Данило отримує частину демонічної сили — це дає можливість переносити душі та використовувати посох як зброю, але кожне використання темної сили збільшує гріх.

### Пролог
8 сцен діалогу між Данилом і Богом. Не можна пропустити (лише перший запуск). Пояснює:
- Чому Данило тут
- Що таке 100 душ
- Навіщо потрібен посох з демонічною силою
- Що станеться якщо знайде всіх

### Повідомлення Бога
Бог спілкується з Данилом через Хаб Раю перед ключовими рівнями (1, 2, 5, 10, 20, 25, 30, 40, 50, 51, 60, 70, 75, 80, 81, 90, 91, 95, 99, 100) та при особливих подіях (прийнята угода з демоном, гріх > 70%, остання душа).

**Налаштування:** `hub_config.json` → `god_messages`

### Кінцівки (6 варіантів)
Визначаються комбінацією кількості знайдених душ і рівня гріху в кінці гри:

| Кінцівка | Умова |
|----------|-------|
| **Прощення** (Saint) | 100 душ + гріх < 20% |
| **Другий шанс** (Redeemed) | 100 душ + гріх 20–50% |
| **Між світами** (Bound) | 100 душ + гріх 51–80% |
| **Новий Демон** (Fallen) | 100 душ + гріх > 80% |
| **Угода** (Traitor) | < 100 душ + прийняв угоду з демоном |
| **Третій шлях** (Rebel) | Особлива умова — прихована |

**Налаштування:** `localization/uk.json` та `en.json` → `endings`

## 3. Механіки гравця

**Скрипт:** `scripts/Player.gd`  
**Конфіг:** `player_mechanics_config.json`

### Рух
| Параметр | Значення |
|----------|---------|
| Швидкість ходьби | 180 px/s |
| Прискорення (земля) | 800 |
| Гальмування | 1200 |
| Прискорення (повітря) | 500 |
| Гравітація | 900 |
| Максимальна швидкість падіння | 600 px/s |
| Coyote time | 0.12 сек |
| Jump buffer | 0.10 сек |

**Coyote time** — гравець може стрибнути ще 0.12 сек після того як зійшов з платформи.  
**Jump buffer** — якщо натиснути стрибок за 0.10 сек до приземлення — стрибок зарахується.

### Variable Jump
Утримуй кнопку стрибка → стрибок вищий (до 0.25 сек утримання).  
Відпустив раніше → стрибок обрізається до мінімальної висоти.

### Посох
Данило використовує посох як захист — він **не вбиває** ворогів, лише відштовхує.

| Параметр | Базово | З апгрейдом |
|----------|--------|-------------|
| Радіус удару | 80 px | +40 px |
| Відстань відльоту ворога | 180 px | — |
| Оглушення ворога | 2.5 сек | — |
| Cooldown | 4.5 сек | 3.0 сек |
| Гріх за удар | +2% | 0% (Чиста Молитва) |

**Обмеження:** посох недоступний коли гравець несе душу (обидві руки зайняті).

### Подвійний стрибок (апгрейд)
Без апгрейду недоступно. З апгрейдом **Легкість Духу** — натиснути стрибок повторно у повітрі → персонаж робить ще один стрибок. Скидається при торканні землі.

### HP та пошкодження
- Базово: 3 HP (серця в HUD)
- Максимум з апгрейдами: 6 HP
- Після удару: 1.2 сек невразливості (блимання спрайту)
- Пошкодження від падіння: якщо впав більше 480 px → −1 HP (з апгрейдом Soft Landing — поріг 720 px)

## 4. Система гріху

Гріх (0–100%) — центральна механіка що визначає кінцівку гри.

### Джерела гріху

| Подія | Зміна |
|-------|-------|
| Удар посохом | +2% |
| Торкнувся міміка | +10% |
| Прийнята угода з демоном | +20% (+10% з апгрейдом) |
| Смерть | +5% |
| Екзорцизм міміка | −3% |
| Завершення рівня (апгрейд Cleansing) | −5% |
| Прихована душа H19 (sin_freeze) | заморожує на 3 рівні |

### Візуальне відображення
Шкала гріху знизу екрана (HUD). Колір змінюється:
- 0–29%: білий
- 30–59%: помаранчевий
- 60–84%: червоний
- 85–100%: темно-червоний

### Вплив на платформи
- **Faith платформа** — стає непрохідною якщо гріх ≥ 50%
- **Sin платформа** — стоячи на ній гріх +2%/сек

**Налаштування:** `hud_config.json` → `sin_bar.colors`

## 5. Механіки душ

**Конфіг:** `soul_mechanics_config.json`

### Загальне правило
**Всі душі (крім міміків) треба донести до виходу.** Підібрав → несеш → вийшов. Без штрафу швидкості — напруга від переслідувачів.

Візуально: душа з'являється над головою гравця, гравець злегка світиться.

### Тип 1 — Невинна душа (Innocent)
- Підібрав торкнувшись → одразу несеш
- Охорона залежить від кола:

| Кола | Охорона |
|------|---------|
| 1–2 | Без охорони або далекий патруль |
| 3–5 | Один ворог впритул |
| 6–8 | Два вороги + пастка |
| 9–10 | Замок — треба активувати механізм |

### Тип 2 — Спляча душа (Sleeping)
1. Підійшов (80 px) → показується іконка + підказка 1.5 сек
2. Стартує рандомна міні-гра з пулу кола
3. Виконав → починаєш нести до виходу
4. Провалив → 20 сек затримки, без штрафу гріху

**Пул міні-ігор по колах:**

| Кола | Доступні типи |
|------|--------------|
| 1–3 | Тиша, Ритм |
| 4–6 | Тиша, Ритм, Вогні |
| 7–8 | Ритм, Вогні, Луна |
| 9–10 | Ритм, Луна, Молитва |

**Міні-ігри:**

| Тип | Іконка | Дія |
|-----|--------|-----|
| Тиша | 🤫 | Стій нерухомо 4 сек |
| Ритм | ♪ | Натискай у такт пульсу (3–5 ударів) |
| Вогні | 🕯 | Збери 3 іскри за 10 сек |
| Луна | 👂 | Послухай патерн → повтори натисканням |
| Молитва | 🙏 | Утримуй кнопку 3 сек (гріх не росте під час утримання) |

### Тип 3 — Душа-пастка / Мімік (Mimic)
Виглядає як звичайна душа, але має візуальні підказки:

| Ознака | Справжня душа | Мімік |
|--------|--------------|-------|
| Пульс | Рівний | Нерегулярний, смикається |
| Тінь | Правильна | Вказує не в той бік |
| Колір | Тепло-білий | Злегка фіолетовий |
| Звук | Тихе сопрано | Легкий дисонанс |

**Варіанти взаємодії:**
- **Утримати кнопку 2 сек поруч** → екзорцизм → мімік розвіюється → гріх −3%, +10 Світла
- **Торкнутись** → гріх +10%, з'являється ворог на 15 сек

Апгрейд **Розпізнавання** підсвічує міміків червоним.

### Система переслідування при підборі душі
Підбір душі видає звук (радіус 200 px). Вороги в радіусі входять в стан ALERT.

| Кола | Час погоні | Швидкість | Макс. переслідувачів |
|------|-----------|-----------|----------------------|
| 1–2 | 4 сек | ×1.1 | 1 |
| 3–4 | 6 сек | ×1.2 | 1 |
| 5–6 | 8 сек | ×1.3 | 2 |
| 7–8 | 10 сек | ×1.4 | 2 |
| 9–10 | 14 сек | ×1.5 | 3 |

Якщо в радіусі більше ворогів ніж ліміт — гоняться найближчі. Решта продовжує патруль.

### Прихована душа
20 прихованих душ (H1–H20) розкидані по всій грі. Видно в сітці колекції завжди (зі знаком ✦ і `?`). Дають унікальні нагороди:
- `sin_freeze_3_levels` — заморозити гріх на 3 рівні
- `reveal_nearby_soul` — підсвітити одну сусідню душу
- `unlock_secret_ending` — розблокувати прихований фінал
- та інші

**Налаштування:**
- Типи та міні-ігри: `soul_mechanics_config.json`
- Список душ та прихованих: `souls_collection.json`
- Тексти імен та епітафій: `localization/uk.json` → `souls`

## 6. Вороги та AI

**Скрипт:** `scripts/enemies/BaseEnemy.gd`  
**Конфіг статів:** `enemies_config.json`  
**Спрайти:** `enemy_sprite_map.json`

### Стейт-машина

```
PATROL → ALERT → CHASE → GIVE_UP → RETURN
                              ↑
                          STUNNED
```

| Стан | Поведінка |
|------|-----------|
| **PATROL** | Ходить між точками, розвертається на стінах та краях |
| **ALERT** | Зупиняється, `!` над головою, 1 сек паузи |
| **CHASE** | Гониться до таймауту, запам'ятовує позицію гравця |
| **GIVE_UP** | `?` над головою, йде до останньої відомої позиції |
| **RETURN** | Повертається на patrol origin |
| **STUNNED** | Від посоха — відлітає, відновлюється через N сек |

### Просторовий звук
Дихання ворога чути з відстані 300 px — ще до того як гравець його бачить. Гравець може орієнтуватись на звук.

### Soul Shield взаємодія
Якщо активний апгрейд **Soul Shield** — 3 сек після підбору душі вороги не реагують на гравця.

## 8. Рівні та генерація

**Конфіги:** `levels_config.json`, `level_generation_config.json`

### Структура гри
10 Кіл × 10 рівнів = 100 рівнів.

### Шаблон кола (позиції 1–10)

Кожне з 10 кіл має однаковий шаблон типів. Позиція 1 завжди статична (наративна). Позиція 10 — бос-арена.

| Позиція в колі | Тип | Душ на рівні |
|----------------|-----|--------------|
| 1 | `vertical` (статичний — наративний) | 1 іменна |
| 2 | `vertical` | 1 іменна + 0–1 звичайна |
| 3 | `void` | 1 іменна + 3–5 звичайних |
| 4 | `vertical` | 1 іменна + 0–1 звичайна |
| 5 | `labyrinth` | 1 іменна + 2–3 звичайних |
| 6 | `vertical` | 1 іменна + 0–1 звичайна |
| 7 | `void` | 1 іменна + 3–5 звичайних |
| 8 | `vertical` | 1 іменна + 0–1 звичайна |
| 9 | `escape` | 1 іменна + 1–2 звичайних |
| 10 | `boss` (статичний) | 1–2 іменних |

> Прихована душа (H1–H20) може з'явитись на будь-якому рівні крім `escape` і `boss`.  
> 1 іменна душа на рівень × 100 рівнів = 100 іменних душ разом.

---

### Типи рівнів — детальна механіка

---

#### `vertical` — Вертикальний

**Суть:** класичний рівень спуску вниз (до виходу в підлозі) або підйому вгору (до виходу в стелі). Напрямок визначається конфігом рівня і змінюється щоразу.

**Структура:**
```
[вхід] → безпечна кімната (без ворогів, 1–2 сек)
       → 3–4 ігрові кімнати (вороги, пастки, полиці)
       → [вихід]
```
Кімнати стикуються вертикально. Ширина рівня: 320–480 px (2–3 екрани), висота: 1200–2000 px залежно від кола.

**Камера:** плавно слідує за гравцем вертикально; горизонтальна мертва зона ±60 px.

**Розміщення душ:**
- Іменна душа — в одній з середніх кімнат, не відразу видна, часто захищена ворогом або закрита платформою.
- Звичайна душа (якщо є) — в окремій ніші збоку, потрібен невеликий стрибковий маневр.

**Win condition:** гравець досягає виходу з душею або без (вихід не блокується).

**Особливості за колами:**
- Кола 1–3: спуск (інтуїтивно — падаємо в пекло).
- Кола 4–7: чергування спуск/підйом (підйом важчий — треба боротися з гравітацією).
- Кола 8–10: підйом (Данило піднімається назад з останніх кіл).

**Душ:** 1 іменна + 0–1 звичайна.

---

#### `void` — Пустота

**Суть:** велика відкрита печера без чіткого напрямку. Нема єдиного шляху — гравець вільно досліджує простір. Вихід прихований або охороняється.

**Структура:**
```
Один великий відкритий простір: ~1600×1200 px (5×4 екрани).
Платформи розкидані нерегулярно. Нема стелі-підлоги як обмежень.
Вихід закритий поки не зібрані всі іменні душі рівня.
```

**Камера:** зум 0.8 (видно більше простору); вільне стеження з lookahead.

**Розміщення душ:**
- Іменна — в глибині печери, часто за природньою перешкодою (промінь вогню, вузький прохід).
- Звичайних 3–5 — розкидані рівномірно, частина видима відразу, частина схована під платформами або в нішах (доступно з `soul_sense`).
- Прихована душа з'являється тут частіше ніж в інших типах.

**Вороги:** патрулюють широкі зони, більша зона виявлення ніж на `vertical`. Кількість на 1 більше ніж стандарт кола.

**Ліміт смертей:** 5 (замість стандартних 3). Після 5-ї смерті — провал рівня, рестарт.

**Win condition:** зібрати іменну душу + всі помічені (підсвічені) звичайні → вихід відкривається.

**Особливості:**
- Немає обов'язку підбирати всі звичайні душі — але кожна дає Світло і +1 до лічильника доставлених.
- Апгрейд `tracker` особливо корисний — показує напрям до найближчої нерозбудженої.
- Апгрейд `map` на старті дає контур усієї печери на 3 сек — критично для орієнтування.

**Душ:** 1 іменна + 3–5 звичайних.

---

#### `labyrinth` — Лабіринт

**Суть:** горизонтальний рівень із заплутаними тунелями. Кілька шляхів, тупики, петлі. Потрібно знайти вихід і по дорозі не загубити душі.

**Структура:**
```
Горизонтальна карта: ~2400×640 px (7–8 екранів завширшки, 2 рівні висоти).
Тунелі з'єднані Y-розгалуженнями. Мінімум 2 тупики на рівень.
Вихід — завжди в правій частині карти.
```

**Камера:** горизонтальне стеження; lookahead 180 px вперед (в напрямку руху).

**Розміщення душ:**
- Іменна — в тупику або за розгалуженням, не на головному шляху.
- Звичайних 2–3 — рівномірно по різних гілках; одна завжди на головному шляху.

**Вороги:** патрулюють вузькі коридори — стикнутися важко без підготовки. Ідеальна арена для `quiet_step` і `distraction`.

**Мінімап:** недоступний (intentionally). Апгрейд `map` дає контур лабіринту на 3 сек на старті — єдина допомога з орієнтування.

**Win condition:** досягти виходу. Душа не обов'язкова для проходу, але іменна завжди в тупику — обхід коштує часу та ризику.

**Особливості:**
- Двері/засуви відсутні — весь лабіринт відкритий одразу.
- На колах 8–9 з'являються міміки в тупиках (виглядають як іменні душі). `recognition` рятує від помилки.
- Пастки (`premonition`) — частіше ніж на `vertical`, особливо в тупиках (punishment за нерозважливий біг).

**Душ:** 1 іменна + 2–3 звичайних.

---

#### `escape` — Втеча

**Суть:** тільки підйом вгору. Знизу піднімається переслідувач (лава, демонічна хвиля, або сутність). Гравець мусить встигнути зібрати душі й вибратись до виходу нагорі.

**Структура:**
```
Вертикальний рівень висотою 2400–3200 px (6–8 екранів).
Одна вертикальна лінія підйому з відгалуженнями-нішами де ховаються душі.
Переслідувач стартує через 2 сек після входу гравця на рівень.
```

**Камера:** зміщена вгору (lookahead 200 px вгору), щоб гравець бачив що попереду. При наближенні переслідувача — легке потрясіння екрану.

**Переслідувач:**
- Швидкість трохи нижча за швидкість гравця без апгрейдів — але підбір душі сповільнює гравця (анімація 0.6 сек якщо нема `quick_pickup`).
- Доторкнувся до переслідувача → −1 HP + відштовхування вгору (не смерть).
- Переслідувач не зупиняється — нема respawn-паузи.

**Розміщення душ:**
- Іменна — приблизно на 60–70% висоти підйому, в ніші збоку від основного шляху (невеликий крюк).
- Звичайних 1–2 — одна на 30% висоти (легко взяти), одна на 80% (ризикована).

**Win condition:** вийти через вихід нагорі. Якщо переслідувач досяг виходу раніше гравця — рівень провалено.

**Особливості:**
- `double_jump` + `jump` × 2 суттєво допомагають — дають вертикальний простір.
- `quick_pickup` критичний — без нього підбір може стати смертельним в тісному місці.
- `soul_shield` (3 сек grace period) — вороги не реагують після підбору, але переслідувач — не ворог, а подія рівня → grace не впливає.
- Respawn — завжди на початку рівня (не в середині). Переслідувач скидається теж.

**Душ:** 1 іменна + 1–2 звичайних.

#### `boss` — Бос-арена

**Суть:** замкнена арена де гравець протистоїть охоронцеві душ. Вбити боса неможливо — перемога через виконання механіки арени. Вихід заблокований поки бос активний.

**Структура:**
```
Статична арена: ~800×600 px (2–3 екрани).
Геометрія підібрана під механіку конкретного боса.
Кілька платформ різної висоти. Нема пасток (арена сама є небезпекою).
```

**Камера:** фіксований зум щоб вся арена була видна одразу (або близько до цього). Без lookahead.

**Розміщення душ:**
- Іменних 1–2 — «звільняються» після перемоги або захищені механікою (бос стоїть між ними і гравцем).
- На колах де бос без назви (40, 60, 80, 90) — 1 іменна, пряме завдання: дістати її поки бос заважає.

**Механіки перемоги (залежать від боса):**
- Зібрати предмети/уламки й добігти до точки активації.
- Активувати тотеми в правильному порядку.
- Тримати молитву (hold) під час паузи боса.
- Оглушити посохом і пройти крізь арену.
- Впізнати справжнього серед копій.

**Стан STUNNED:** удар посохом оглушує на 6 сек. Більшість механік вимагають оглушення як умову для наступного кроку. Посох → оглушення → дія → повторити.

**Win condition:** механіко-специфічна (сигнал `win_condition_met` від BossAI). Після перемоги — вихід відкривається, іменні душі стають доступними для підбору.

**Особливості:**
- Бос-рівні завжди статичні (не процедурні).
- Смертей ліміту немає — можна гинути скільки завгодно.
- `faith_shield` (авто-блок 1/рівень) — єдиний рятівний апгрейд проти першого неочікуваного удару.

**Душ:** 1–2 іменних (після перемоги).

### Гібридна генерація

**Статичні (~35 рівнів):**
- Перший рівень кожного кола (1, 11, 21...91) — наративні
- Бос-рівні (10, 20, 30, 50, 70, 100)
- Всі 20 рівнів з прихованими душами
- Мілстоуни (50, 75, 99, 100)

**Процедурні (~65 рівнів):**
- Збираються з кімнат-блоків при завантаженні
- Seed = ID рівня → однаковий рівень завжди однаковий
- Структура: `вхід (безпечний) → 1–4 основні кімнати → вихід`
- 20–30 кімнат на коло в пулі

### Складність всередині кола

## 12. Збереження

- Поточний рівень та коло
- Зібрані душі та приховані душі

- Поточний гріх
- Налаштування (звук, мова, графіка)
- Прапорець `no_ads_purchased`
- Переглянуті підказки туторіалу

Кнопки: Грати / Збережені Душі / Налаштування / Без реклами / Підтримати / Вийти.

Слоти збереження: показують поточне коло, рівень, кількість душ, час гри.

### Налаштування
**Конфіг:** `settings_config.json`

3 вкладки:
- **Звук:** Master / Music / SFX слайдери (0–100), Вимкнути все
- **Мова:** Українська / English (застосовується миттєво)
- **Графіка:** Повноекранний, Роздільна здатність (якщо не fullscreen), Якість Low/Medium/High, V-Sync

Зберігається в `user://settings.json` при кожній зміні.

## 14. Музика та звуки

**Конфіг:** `audio_config.json`

### Аудіо шини
- **Master** — глобальна гучність
- **Music** — фонова музика
- **SFX** — всі ефекти

### Адаптивна музика
Кожне коло має 4 шари що змішуються в реальному часі:

| Шар | Коли активний |
|-----|--------------|
| `base` | Завжди |
| `tension` | Ворог помітив (ALERT) |
| `chase` | Активне переслідування |
| `carry` | Гравець несе душу |

Crossfade між станами: 0.8–1.5 сек. Немає різких переключень.

### Характер музики по колах

| Коло | Назва | Стиль |
|------|-------|-------|
| 1 | Передпокій | Майже тиша, поодинокі ноти фортепіано |
| 2 | Вітри | Завивання вітру як мелодія |
| 3 | Вогонь | Ритмічні барабани, тріск вогню |
| 4 | Болота | Важка, в'язка, повільний пульс |
| 5 | Гнів | Дисонанс, різкі акценти |
| 6 | Єресь | Готичний орган, спотворені псалми |
| 7 | Насильство | Гнітюча, низькі частоти |
| 8 | Обман | Механічний годинник, музична шкатулка |
| 9 | Зрада | Холодна порожнеча, льодяні тони |
| 10 | Трон | Монументальна, повний оркестр + хор |

**Коли Бог говорить:** музика приглушується до −18 dB + реверб "собору".

### Просторовий звук
- Дихання ворога чути за 300 px (ще до виявлення)
- Душа гудить за 250 px (можна шукати на слух)

## 16. Туторіал

**Конфіг:** `tutorial_config.json`

### Принцип
Контекстний — підказки з'являються при першій зустрічі з механікою. Не окремий режим.  
Кожна підказка = **текст + іконка кнопки + візуальна демонстрація**.

### Типи візуалізації

| Тип | Використання |
|-----|-------------|
| Напівпрозорий силует гравця | Показує рух, стрибок, посох, несення душі |
| Пульсуючий жовтий контур | Виділяє важливий об'єкт |
| Анімована стрілка | Вказує куди йти |
| Кнопка натискається | Для разових дій |
| Кнопка з прогрес-баром | Для утримань |

### Коли з'являються підказки

| Підказка | Рівень | Тригер |
|----------|--------|--------|
| Рух | 1 | Старт рівня |
| Стрибок | 1 | При наближенні до першої ями |
| Variable jump | 1 | Після першого стрибка |
| Підбір душі | 1 | Поруч з першою душею (100 px) |
| Донести до виходу | 1 | Після підбору |
| Уникання ворогів | 1 | Перший ворог в полі зору |
| Переслідування | 2 | Перша погоня |
| One-way платформа | 2 | Поруч з першою (80 px) |
| Crumbling платформа | 2 | Поруч (60 px) |
| Посох | 3 | Ворог блокує єдиний прохід |
| Посох + гріх | 3 | Після першого удару |
| Спляча душа | 5 | Поруч (120 px) |
| Міні-гра | 5 | При старті першої міні-гри |
| Мімік | 7 | Поруч (150 px) |
| Екзорцизм | 7 | Якщо стоїш 2 сек поруч з міміком |
| Faith платформа | 51 | Поруч (100 px) |
| Soul bridge | 61 | Поруч (100 px) |

**Виняток:** підказка до міні-гри сплячої душі показується **кожного разу** (бо рандомна, 1.5 сек).  
**NG+:** всі підказки вимкнені автоматично.

## 17. Монетизація

**Конфіг:** `monetization_config.json`  
**Скрипт:** `scripts/AdsManager.gd` (Autoload: `AdsManager`)

### Реклама (AdMob)

**Banner:**
- Адаптивний, знизу екрана, висота 60 px
- Гра зміщена вгору на 60 px щоб не перекривати UI
- Вміст реклами контролює Google — розробник тільки викликає `load_banner()`

**Interstitial (повноекранна):**
- Показується при: завантаженні рівня, переході до хабу, переході до наступного рівня
- Не частіше ніж раз на 2 хвилини
- Завантажується заздалегідь щоб не було затримки

### Покупки (Google Play IAP)

**Без реклами — $4 (one-time):**
- Banner знищується, гра займає весь екран
- Зберігається в save + перевіряється через Google Play при кожному запуску
- Кнопка в меню змінюється на "Реклама відключена ✓"

**Donate — $1 / $3 / $5 / $10 (consumable):**
- Можна купувати кілька разів
- Ніякого ігрового ефекту — тільки подяка
- Назви в тематиці гри: "Дрібна монета" → "Благодать"

### Тестовий режим
У debug-збірці автоматично використовуються тестові AdMob ID — не порушує правила Google.

## 18. Довідник конфігів

Усі конфіги лежать в корені проекту. Змінюй значення тут — код підхоплює автоматично.

---

### `levels_config.json`
Всі 100 рівнів. Для кожного рівня:
- `enemies` — які вороги присутні
- `traps` — які пастки
- `bonuses` — які бонуси можна підібрати
- `soul_types` — типи душ (innocent / sleeping / mimic)
- `special_mechanics` — особливі механіки (wind_push, darkness тощо)
- `difficulty` — базова складність

---

### `level_generation_config.json`
- `static_levels` — які рівні статичні (не генеруються)
- `room_pools` — пули кімнат для кожного кола
- `difficulty_injection` — модифікатори складності в межах кола
- `level_type_distribution` — шаблон розподілу типів рівнів в колі

---

### `souls_collection.json`
- Всі 100 іменних душ: ім'я, вік, коло, рівень, тип, гріх
- 20 прихованих душ: ім'я, підказка, нагорода

---

### `soul_mechanics_config.json`
- `soul_types` — параметри кожного типу (innocent / sleeping / mimic)
- `sleeping.minigame_pool_by_circles` — які міні-ігри доступні в яких колах
- `sleeping.minigames` — параметри кожної міні-гри (тривалість, умова провалу)
- `mimic.exorcism` — тривалість утримання, нагорода, штраф
- `carrying_mechanic` — поведінка при смерті з душею
- `enemy_chase.scaling_by_circle` — час погоні, швидкість, макс. переслідувачів

---

### `enemies_config.json`
Для кожного ворога:
- `move_speed` — швидкість патрулю
- `detection_range` — радіус виявлення гравця
- `patrol_distance` — довжина маршруту патрулю
- `alert_duration` — тривалість фази ALERT
- `special` — особлива здібність (knockback_resistance, sin_aura тощо)

---

### `enemy_sprite_map.json`
- `base_path` — базовий шлях `res://Assets/enemies/`
- Для кожного ворога: `pack`, `character`, `animations` (маппінг назв анімацій)

---

### `bosses_config.json`
Для кожного боса:
- `stats` — швидкість, дальність виявлення
- `mechanic` — тип і опис механіки, умова перемоги
- `arena` — розміри та платформи арени
- `phases` — для Люцифера: умови переходу між фазами

---

### `platforms_config.json`
Для кожного типу платформи:
- `behavior` — поведінка (solid_always, breaks_after_standing тощо)
- Специфічні параметри: `delay_before_break`, `friction`, `sin_per_second`, `sin_threshold` тощо
- `circles` — в яких колах з'являється
- `sound_loop`, `sound_break` — звуки

---

### `placeholder_assets_config.json`
- `color` — колір прямокутника для кожного типу об'єкта
- `size` — розмір [width, height]
- `opacity` — прозорість (для напівпрозорих платформ)
- `label` — текст підпису

---

### `upgrades_config.json`
- `currency` — скільки Світла дає кожна дія
- Для кожного апгрейду: `cost`, `max_level`, `effect` (тип і значення)

---

### `camera_config.json`
- `lookahead_distance` — на скільки камера дивиться вперед (120 px)
- `direction_change_delay` — затримка при розвороті (0.3 сек)
- `vertical_deadzone` — мертва зона по вертикалі
- `void_level_zoom` — зум на void рівнях (0.8)

---

### `hud_config.json`
- `sin_bar.colors` — кольори шкали гріху по порогах
- `level_info.fade_after` — через скільки сек зникає назва рівня (3 сек)
- `bonus_slots.expiring_threshold` — за скільки сек до кінця бонус блимає (3 сек)

---

### `hub_config.json`
- `god_messages` — повідомлення по рівнях і подіях
- `prologue_scenes` — сцени вступного діалогу
- `message_styles` — стилі повідомлень (calm / warning / personal тощо)

---

### `death_system_config.json`
- `limits` — ліміти смертей по типах рівнів
- `soft_limit_sin_penalty` — скільки гріху за перевищення (5%)
- `respawn_points` — де respawn по типах рівнів

---

### `settings_config.json`
- `tabs` — вкладки налаштувань (sound / language / graphics)
- Для кожного контролу: `type`, `default`, `min/max` (для слайдерів)
- `save.path` — куди зберігати (`user://settings.json`)

---

### `audio_config.json`
- `music.tracks` — треки для кожного кола та особливих моментів
- `music.system.crossfade_duration` — тривалість переходу між треками
- `sfx` — шляхи до всіх звукових ефектів по категоріях
- `spatial_audio` — дальність просторових звуків

---

### `collection_screen_config.json`
- `grid.columns` — кількість колонок сітки (8)
- `cell_states` — візуальні стани клітинок
- `counters.hidden.visible` — чи показувати лічильник ✦ завжди

---

### `level_complete_config.json`
- `stars.rules` — умови для 1/2/3 зірок
- `stats.items` — які статистики показувати
- `sounds` — звуки для кожної зірки

---

### `pause_screen_config.json`
- `background.blur_amount` — сила розмиття (4.0)
- `exit_confirmation` — тексти підтвердження виходу

---

### `tutorial_config.json`
- `settings.hint_display_duration` — скільки секунд показується підказка (4 сек)
- `settings.exceptions.minigame_hint` — підказка міні-гри завжди (1.5 сек)
- `triggers` — умови появи кожної підказки (рівень, тригер, відстань)
- `visual_demos.per_trigger` — тип демонстрації для кожної підказки

---

### `monetization_config.json`
- `admob.banner.unit_id_release` — **сюди вставляєш свій AdMob Banner ID**
- `admob.interstitial.unit_id_release` — **сюди вставляєш свій Interstitial ID**
- `admob.interstitial.cooldown_seconds` — мінімальний інтервал між рекламою (120 сек)
- `admob.interstitial.show_on` — коли показувати повноекранну рекламу
- `admob.banner.enabled` / `admob.interstitial.enabled` — вмикання/вимикання
- `iap.no_ads.sku` — SKU для покупки "Без реклами" в Google Play Console
- `iap.donate.tiers` — список SKU для донатів
- `layout.banner_height_px` — висота банера в пікселях (60)

---

### `localization/uk.json` та `localization/en.json`
Всі тексти гри згруповані за простором імен.  
Щоб додати нову мову — створи новий файл (`fr.json`, `de.json` тощо) з тими ж ключами і додай її в `settings_config.json` → `tabs[language].controls[language_select].available`.
