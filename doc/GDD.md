## 1. Огляд гри

**Escape from Hell** — одиночний 2D платформер де гравець керує колишнім священиком Данилом, який спускається крізь 10 кіл пекла щоб врятувати 100 душ що потрапили туди помилково.

### Ключові особливості
- 100 рівнів в 10 колах пекла
- 100 іменних душ з унікальними історіями + 20 прихованих
- Уникання ворогів замість бою (посох лише відштовхує)
- Система гріху що впливає на кінцівку
- 6 різних кінцівок залежно від дій гравця
- Гібридна генерація рівнів (статичні + процедурні)
- Адаптивна музика з шарами
- Android з банерною рекламою та опцією "Без реклами"

## 2. Історія та персонаж

### Данило — колишній священик
Колишній священик що втратив віру. Помер і потрапив між небом і пеклом. Бог дає йому завдання: врятувати 100 душ що опинились у пеклі через бюрократичну помилку.

Щоб вижити в пеклі Данило отримує частину демонічної сили — це дає можливість переносити душі та використовувати посох як зброю, але кожне використання темної сили збільшує гріх.

### Пролог
8 сцен діалогу між Данилом і Богом. Не можна пропустити (лише перший запуск). Пояснює:
- Чому Данило тут
- Що таке 100 душ
- Навіщо потрібен посох з демонічною силою
- Що станеться якщо знайде всіх

### Повідомлення Бога
Бог спілкується з Данилом через Хаб Раю перед ключовими рівнями (1, 2, 5, 10, 20, 25, 30, 40, 50, 51, 60, 70, 75, 80, 81, 90, 91, 95, 99, 100) та при особливих подіях (прийнята угода з демоном, гріх > 70%, остання душа).

**Налаштування:** `hub_config.json` → `god_messages`

### Кінцівки (6 варіантів)
Визначаються комбінацією кількості знайдених душ і рівня гріху в кінці гри:

| Кінцівка | Умова |
|----------|-------|
| **Прощення** (Saint) | 100 душ + гріх < 20% |
| **Другий шанс** (Redeemed) | 100 душ + гріх 20–50% |
| **Між світами** (Bound) | 100 душ + гріх 51–80% |
| **Новий Демон** (Fallen) | 100 душ + гріх > 80% |
| **Угода** (Traitor) | < 100 душ + прийняв угоду з демоном |
| **Третій шлях** (Rebel) | Особлива умова — прихована |

**Налаштування:** `localization/uk.json` та `en.json` → `endings`

## 3. Механіки гравця

**Скрипт:** `scripts/Player.gd`  
**Конфіг:** `player_mechanics_config.json`

### Рух
| Параметр | Значення |
|----------|---------|
| Швидкість ходьби | 180 px/s |
| Прискорення (земля) | 800 |
| Гальмування | 1200 |
| Прискорення (повітря) | 500 |
| Гравітація | 900 |
| Максимальна швидкість падіння | 600 px/s |
| Coyote time | 0.12 сек |
| Jump buffer | 0.10 сек |

**Coyote time** — гравець може стрибнути ще 0.12 сек після того як зійшов з платформи.  
**Jump buffer** — якщо натиснути стрибок за 0.10 сек до приземлення — стрибок зарахується.

### Variable Jump
Утримуй кнопку стрибка → стрибок вищий (до 0.25 сек утримання).  
Відпустив раніше → стрибок обрізається до мінімальної висоти.

### Посох
Данило використовує посох як захист — він **не вбиває** ворогів, лише відштовхує.

| Параметр | Базово | З апгрейдом |
|----------|--------|-------------|
| Радіус удару | 80 px | +40 px |
| Відстань відльоту ворога | 180 px | — |
| Оглушення ворога | 2.5 сек | — |
| Cooldown | 4.5 сек | 3.0 сек |
| Гріх за удар | +2% | 0% (Чиста Молитва) |

**Обмеження:** посох недоступний коли гравець несе душу (обидві руки зайняті).

### Wall Grab (апгрейд)
Без апгрейду недоступно. З апгрейдом — затиснути напрямок у стіну під час падіння → персонаж чіпляється і висить 2 секунди.

### HP та пошкодження
- Базово: 3 HP (серця в HUD)
- Максимум з апгрейдами: 6 HP
- Після удару: 1.2 сек невразливості (блимання спрайту)
- Пошкодження від падіння: якщо впав більше 480 px → −1 HP (з апгрейдом Soft Landing — поріг 720 px)

## 4. Система гріху

Гріх (0–100%) — центральна механіка що визначає кінцівку гри.

### Джерела гріху

| Подія | Зміна |
|-------|-------|
| Удар посохом | +2% |
| Торкнувся міміка | +10% |
| Прийнята угода з демоном | +20% (+10% з апгрейдом) |
| Смерть | +5% |
| Екзорцизм міміка | −3% |
| Завершення рівня (апгрейд Cleansing) | −5% |
| Прихована душа H19 (sin_freeze) | заморожує на 3 рівні |

### Візуальне відображення
Шкала гріху знизу екрана (HUD). Колір змінюється:
- 0–29%: білий
- 30–59%: помаранчевий
- 60–84%: червоний
- 85–100%: темно-червоний

### Вплив на платформи
- **Faith платформа** — стає непрохідною якщо гріх ≥ 50%
- **Sin платформа** — стоячи на ній гріх +2%/сек

**Налаштування:** `hud_config.json` → `sin_bar.colors`

## 5. Механіки душ

**Конфіг:** `soul_mechanics_config.json`

### Загальне правило
**Всі душі (крім міміків) треба донести до виходу.** Підібрав → несеш → вийшов. Без штрафу швидкості — напруга від переслідувачів.

Візуально: душа з'являється над головою гравця, гравець злегка світиться.

### Тип 1 — Невинна душа (Innocent)
- Підібрав торкнувшись → одразу несеш
- Охорона залежить від кола:

| Кола | Охорона |
|------|---------|
| 1–2 | Без охорони або далекий патруль |
| 3–5 | Один ворог впритул |
| 6–8 | Два вороги + пастка |
| 9–10 | Замок — треба активувати механізм |

### Тип 2 — Спляча душа (Sleeping)
1. Підійшов (80 px) → показується іконка + підказка 1.5 сек
2. Стартує рандомна міні-гра з пулу кола
3. Виконав → починаєш нести до виходу
4. Провалив → 20 сек затримки, без штрафу гріху

**Пул міні-ігор по колах:**

| Кола | Доступні типи |
|------|--------------|
| 1–3 | Тиша, Ритм |
| 4–6 | Тиша, Ритм, Вогні |
| 7–8 | Ритм, Вогні, Луна |
| 9–10 | Ритм, Луна, Молитва |

**Міні-ігри:**

| Тип | Іконка | Дія |
|-----|--------|-----|
| Тиша | 🤫 | Стій нерухомо 4 сек |
| Ритм | ♪ | Натискай у такт пульсу (3–5 ударів) |
| Вогні | 🕯 | Збери 3 іскри за 10 сек |
| Луна | 👂 | Послухай патерн → повтори натисканням |
| Молитва | 🙏 | Утримуй кнопку 3 сек (гріх не росте під час утримання) |

### Тип 3 — Душа-пастка / Мімік (Mimic)
Виглядає як звичайна душа, але має візуальні підказки:

| Ознака | Справжня душа | Мімік |
|--------|--------------|-------|
| Пульс | Рівний | Нерегулярний, смикається |
| Тінь | Правильна | Вказує не в той бік |
| Колір | Тепло-білий | Злегка фіолетовий |
| Звук | Тихе сопрано | Легкий дисонанс |

**Варіанти взаємодії:**
- **Утримати кнопку 2 сек поруч** → екзорцизм → мімік розвіюється → гріх −3%, +10 Світла
- **Торкнутись** → гріх +10%, з'являється ворог на 15 сек

Апгрейд **Розпізнавання** підсвічує міміків червоним.

### Система переслідування при підборі душі
Підбір душі видає звук (радіус 200 px). Вороги в радіусі входять в стан ALERT.

| Кола | Час погоні | Швидкість | Макс. переслідувачів |
|------|-----------|-----------|----------------------|
| 1–2 | 4 сек | ×1.1 | 1 |
| 3–4 | 6 сек | ×1.2 | 1 |
| 5–6 | 8 сек | ×1.3 | 2 |
| 7–8 | 10 сек | ×1.4 | 2 |
| 9–10 | 14 сек | ×1.5 | 3 |

Якщо в радіусі більше ворогів ніж ліміт — гоняться найближчі. Решта продовжує патруль.

### Прихована душа
20 прихованих душ (H1–H20) розкидані по всій грі. Видно в сітці колекції завжди (зі знаком ✦ і `?`). Дають унікальні нагороди:
- `sin_freeze_3_levels` — заморозити гріх на 3 рівні
- `reveal_nearby_soul` — підсвітити одну сусідню душу
- `unlock_secret_ending` — розблокувати прихований фінал
- та інші

**Налаштування:**
- Типи та міні-ігри: `soul_mechanics_config.json`
- Список душ та прихованих: `souls_collection.json`
- Тексти імен та епітафій: `localization/uk.json` → `souls`

## 6. Вороги та AI

**Скрипт:** `scripts/enemies/BaseEnemy.gd`  
**Конфіг статів:** `enemies_config.json`  
**Спрайти:** `enemy_sprite_map.json`

### Стейт-машина

```
PATROL → ALERT → CHASE → GIVE_UP → RETURN
                              ↑
                          STUNNED
```

| Стан | Поведінка |
|------|-----------|
| **PATROL** | Ходить між точками, розвертається на стінах та краях |
| **ALERT** | Зупиняється, `!` над головою, 1 сек паузи |
| **CHASE** | Гониться до таймауту, запам'ятовує позицію гравця |
| **GIVE_UP** | `?` над головою, йде до останньої відомої позиції |
| **RETURN** | Повертається на patrol origin |
| **STUNNED** | Від посоха — відлітає, відновлюється через N сек |

### Просторовий звук
Дихання ворога чути з відстані 300 px — ще до того як гравець його бачить. Гравець може орієнтуватись на звук.

### Soul Shield взаємодія
Якщо активний апгрейд **Soul Shield** — 3 сек після підбору душі вороги не реагують на гравця.

## 7. Типи платформ

| Тип | Колір (placeholder) | Поведінка |
|-----|---------------------|-----------|
| `stone` | Сірий | Звичайна тверда |
| `one_way` | Світло-сірий | Тверда лише зверху, можна стрибнути крізь знизу |

### Рухомі
| Тип | Колір | Поведінка |
|-----|-------|-----------|
| `moving_horizontal` | Синій | Рухається ліво-право |

| Тип | Колір | Поведінка |
|-----|-------|-----------|
| `crumbling` | Коричневий | Тремтить 0.8 сек → падає через 1.2 сек → відновлюється через 5 сек |

|-----|-------|-----------|

| `ice` | Блакитний | Майже без тертя, гравець ковзає (Коло 9) |
| `sin_platform` | Темно-червоний | Гріх +2%/сек поки стоїш |

### Особливі
| Тип | Колір | Поведінка |
|-----|-------|-----------|
| `faith` | Жовтуватий | Тверда якщо гріх < 50%, інакше примара |
| `soul_bridge` | Синій напівпрозорий | Невидима без душі в руках, з душею — з'являється |
| `illusory` | Фіолетовий напівпрозорий | Зникає при торканні, повертається через 3 сек |
| `conveyor` | Жовтий | Штовхає гравця горизонтально (Коло 8) |
| `bounce` | Зелений | Підкидає вище звичайного стрибка ×2.2 |
| `chain` | Жовто-сірий | Гойдається як маятник 45°, треба зістрибнути в момент |
| `pressure_plate` | Блакитний | Стій → механізм активний. Зійшов → вимикається. |

## 8. Рівні та генерація

**Конфіги:** `levels_config.json`, `level_generation_config.json`

### Структура гри
10 Кіл × 10 рівнів = 100 рівнів.

### Типи рівнів (шаблон кола)
Кожне коло має однаковий шаблон розміщення типів:

| Позиція в колі | Тип рівня |
|----------------|-----------|
| 1 | platformer (статичний — наративний) |
| 2 | platformer |
| 3 | vertical |
| 4 | platformer |
| 5 | labyrinth |
| 6 | platformer |
| 7 | void |
| 8 | platformer |
| 9 | escape |
| 10 | boss (статичний) |

**Типи рівнів:**
- `platformer` — класичний горизонтальний
- `vertical` — рухатись вгору або вниз
- `labyrinth` — заплутана карта, треба знайти вихід
- `void` — велика відкрита локація з багатьма душами (5 смертей ліміт)
- `escape` — тікати від небезпеки (таймер або переслідувач)
- `boss` — статична бос-арена

### Гібридна генерація

**Статичні (~35 рівнів):**
- Перший рівень кожного кола (1, 11, 21...91) — наративні
- Бос-рівні (10, 20, 30, 50, 70, 100)
- Всі 20 рівнів з прихованими душами
- Мілстоуни (50, 75, 99, 100)

**Процедурні (~65 рівнів):**
- Збираються з кімнат-блоків при завантаженні
- Seed = ID рівня → однаковий рівень завжди однаковий
- Структура: `вхід (безпечний) → 1–4 основні кімнати → вихід`
- 20–30 кімнат на коло в пулі

### Складність всередині кола

| Рівні в колі | Вороги | Пастки | Кімнат |
|-------------|--------|--------|--------|
| 1–3 | −1 | low | 3 |
| 4–6 | базово | medium | 4 |
| 7–9 | +1 | high | 5 |
| 10 | бос (статичний) | — | — |

## 9. Боси

**Конфіг:** `bosses_config.json`

Босів **не можна вбити**. Перемога через навігацію, механіки арени, посох для оглушення (6 сек).

| Бос | Рівень | Механіка | Спрайт |

## 13. UI Екрани

**Конфіг:** `hud_config.json`

| Елемент | Позиція | Опис |
|---------|---------|------|
| Серця (HP) | Верхній лівий | Іконки серць |
| Інфо рівня | Верхній центр | "Коло X • Рівень Y" — зникає через 3 сек |

| Активні бонуси | Нижній центр | Іконки активних бонусів |
| Душі рівня | Нижній правий | X / Y на поточному рівні |
| Шкала гріху | Низ (повна ширина) | Кольорова шкала 0–100% |

**Стани бонусів:**
- Активний: нормально
- Закінчується (< 3 сек): блимає червоним
- Закінчився: плавно зникає

### Пауза
**Конфіг:** `pause_screen_config.json`  
Trigger: кнопка пауза або Escape. Blur overlay.

Кнопки: Продовжити / Колекція / Налаштування / Головне меню  
При виборі "Головне меню" — підтвердження з попередженням що душа в руках буде втрачена.

### Level Complete
**Конфіг:** `level_complete_config.json`

Зірки:
- ★★★ — всі душі + 0 смертей
- ★★☆ — всі душі + ≤ 2 смерті
- ★☆☆ — інакше

Показує: душі / смерті / приріст гріху / зароблене Світло / портрети знайдених душ.  
Кнопки: Хаб Раю / Наступний рівень.

### Колекція душ
**Конфіг:** `collection_screen_config.json`

Сітка 8 колонок. Стани:
- Збережена звичайна: срібна рамка
- Збережена прихована: золота рамка + ✦
- Не знайдена звичайна: темна + ?
- Не знайдена прихована: золота рамка + ? (видима завжди)

Лічильник ✦ завжди видимий. Доступна з головного меню та паузи.

При 100/100: теплий блиск + тихий дзвін + маленький текстовий попап.

### Хаб Раю
**Конфіг:** `hub_config.json`

З'являється перед кожним рівнем (можна пропустити). Показує повідомлення Бога, стан гравця, кнопку старту. Пролог (рівень 1) — не можна пропустити.

### Головне меню
Кнопки: Грати / Збережені Душі / Налаштування / Без реклами / Підтримати / Вийти.

Слоти збереження: показують поточне коло, рівень, кількість душ, час гри.

### Налаштування
**Конфіг:** `settings_config.json`

3 вкладки:
- **Звук:** Master / Music / SFX слайдери (0–100), Вимкнути все
- **Мова:** Українська / English (застосовується миттєво)
- **Графіка:** Повноекранний, Роздільна здатність (якщо не fullscreen), Якість Low/Medium/High, V-Sync

Зберігається в `user://settings.json` при кожній зміні.

## 18. Довідник конфігів

Усі конфіги лежать в корені проекту. Змінюй значення тут — код підхоплює автоматично.

---

### `levels_config.json`
Всі 100 рівнів. Для кожного рівня:
- `enemies` — які вороги присутні
- `traps` — які пастки
- `bonuses` — які бонуси можна підібрати
- `soul_types` — типи душ (innocent / sleeping / mimic)
- `special_mechanics` — особливі механіки (wind_push, darkness тощо)
- `difficulty` — базова складність

---

### `level_generation_config.json`
- `static_levels` — які рівні статичні (не генеруються)
- `room_pools` — пули кімнат для кожного кола
- `difficulty_injection` — модифікатори складності в межах кола
- `level_type_distribution` — шаблон розподілу типів рівнів в колі

---

### `souls_collection.json`
- Всі 100 іменних душ: ім'я, вік, коло, рівень, тип, гріх
- 20 прихованих душ: ім'я, підказка, нагорода

---

### `soul_mechanics_config.json`
- `soul_types` — параметри кожного типу (innocent / sleeping / mimic)
- `sleeping.minigame_pool_by_circles` — які міні-ігри доступні в яких колах
- `sleeping.minigames` — параметри кожної міні-гри (тривалість, умова провалу)
- `mimic.exorcism` — тривалість утримання, нагорода, штраф
- `carrying_mechanic` — поведінка при смерті з душею
- `enemy_chase.scaling_by_circle` — час погоні, швидкість, макс. переслідувачів

---

### `enemies_config.json`
Для кожного ворога:
- `move_speed` — швидкість патрулю
- `detection_range` — радіус виявлення гравця
- `patrol_distance` — довжина маршруту патрулю
- `alert_duration` — тривалість фази ALERT
- `special` — особлива здібність (knockback_resistance, sin_aura тощо)

---

### `enemy_sprite_map.json`
- `base_path` — базовий шлях `res://Assets/enemies/`
- Для кожного ворога: `pack`, `character`, `animations` (маппінг назв анімацій)

---

### `bosses_config.json`
Для кожного боса:
- `stats` — швидкість, дальність виявлення
- `mechanic` — тип і опис механіки, умова перемоги
- `arena` — розміри та платформи арени
- `phases` — для Люцифера: умови переходу між фазами

---

### `platforms_config.json`
Для кожного типу платформи:
- `behavior` — поведінка (solid_always, breaks_after_standing тощо)
- Специфічні параметри: `delay_before_break`, `friction`, `sin_per_second`, `sin_threshold` тощо
- `circles` — в яких колах з'являється
- `sound_loop`, `sound_break` — звуки

---

### `placeholder_assets_config.json`
- `color` — колір прямокутника для кожного типу об'єкта
- `size` — розмір [width, height]
- `opacity` — прозорість (для напівпрозорих платформ)
- `label` — текст підпису

---

### `upgrades_config.json`
- `currency` — скільки Світла дає кожна дія
- Для кожного апгрейду: `cost`, `max_level`, `effect` (тип і значення)

---

### `camera_config.json`
- `lookahead_distance` — на скільки камера дивиться вперед (120 px)
- `direction_change_delay` — затримка при розвороті (0.3 сек)
- `vertical_deadzone` — мертва зона по вертикалі
- `void_level_zoom` — зум на void рівнях (0.8)

---

### `hud_config.json`
- `sin_bar.colors` — кольори шкали гріху по порогах
- `level_info.fade_after` — через скільки сек зникає назва рівня (3 сек)
- `bonus_slots.expiring_threshold` — за скільки сек до кінця бонус блимає (3 сек)

---

### `hub_config.json`
- `god_messages` — повідомлення по рівнях і подіях
- `prologue_scenes` — сцени вступного діалогу
- `message_styles` — стилі повідомлень (calm / warning / personal тощо)

---

### `death_system_config.json`
- `limits` — ліміти смертей по типах рівнів
- `soft_limit_sin_penalty` — скільки гріху за перевищення (5%)
- `respawn_points` — де respawn по типах рівнів

---

### `settings_config.json`
- `tabs` — вкладки налаштувань (sound / language / graphics)
- Для кожного контролу: `type`, `default`, `min/max` (для слайдерів)
- `save.path` — куди зберігати (`user://settings.json`)

---

### `audio_config.json`
- `music.tracks` — треки для кожного кола та особливих моментів
- `music.system.crossfade_duration` — тривалість переходу між треками
- `sfx` — шляхи до всіх звукових ефектів по категоріях
- `spatial_audio` — дальність просторових звуків

---

### `collection_screen_config.json`
- `grid.columns` — кількість колонок сітки (8)
- `cell_states` — візуальні стани клітинок
- `counters.hidden.visible` — чи показувати лічильник ✦ завжди

---

### `level_complete_config.json`
- `stars.rules` — умови для 1/2/3 зірок
- `stats.items` — які статистики показувати
- `sounds` — звуки для кожної зірки

---

### `pause_screen_config.json`
- `background.blur_amount` — сила розмиття (4.0)
- `exit_confirmation` — тексти підтвердження виходу

---

### `tutorial_config.json`
- `settings.hint_display_duration` — скільки секунд показується підказка (4 сек)
- `settings.exceptions.minigame_hint` — підказка міні-гри завжди (1.5 сек)
- `triggers` — умови появи кожної підказки (рівень, тригер, відстань)
- `visual_demos.per_trigger` — тип демонстрації для кожної підказки

---

### `monetization_config.json`
- `admob.banner.unit_id_release` — **сюди вставляєш свій AdMob Banner ID**
- `admob.interstitial.unit_id_release` — **сюди вставляєш свій Interstitial ID**
- `admob.interstitial.cooldown_seconds` — мінімальний інтервал між рекламою (120 сек)
- `admob.interstitial.show_on` — коли показувати повноекранну рекламу
- `admob.banner.enabled` / `admob.interstitial.enabled` — вмикання/вимикання
- `iap.no_ads.sku` — SKU для покупки "Без реклами" в Google Play Console
- `iap.donate.tiers` — список SKU для донатів
- `layout.banner_height_px` — висота банера в пікселях (60)

---

### `localization/uk.json` та `localization/en.json`
Всі тексти гри згруповані за простором імен.  
Щоб додати нову мову — створи новий файл (`fr.json`, `de.json` тощо) з тими ж ключами і додай її в `settings_config.json` → `tabs[language].controls[language_select].available`.
