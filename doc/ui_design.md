## HUD (під час гри)

```
┌─────────────────────────────────────────────────────────┐
│  ♥♥♥♡♡♡          Коло 1 • Рівень 3         👻 12 / 100 │
│                                                          │
│                                                          │
│                     [ ІГРОВИЙ СВІТ ]                    │
│                                                          │
│                                                          │
│  [Staff] [Bonus]     👻 активні бонуси    👻 2 / 5      │
│══════════════════════ SIN BAR ══════════════════════════│
└─────────────────────────────────────────────────────────┘
```

| Елемент | Позиція | Опис |
|---------|---------|------|
| Здоров'я | верх-ліво | ♥ сердечка, максимум 6, анімація shake при пошкодженні |
| Інфо рівня | верх-центр | "Коло X • Рівень Y" — показується 3 сек на початку, потім ховається |
| Лічильник душ (всього) | верх-право | `{saved} / 100`, пульсує при збільшенні |
| Слоти здібностей | низ-ліво | Staff CD + активні бонуси |
| Лічильник душ (рівень) | низ-право | `{found} / {total}` на поточному рівні |
| Sin Bar | низ-повна ширина | тонка смужка 6px; білий 0–29%, жовтий 30–59%, червоний 60%+ |

**Sin Bar кольори:**
- `0–29%` — білий `#FFFFFF`
- `30–59%` — жовтий `#FFAA00`
- `60–84%` — помаранчево-червоний `#FF4400`
- `85–100%` — темно-червоний `#AA0000`, пульсує

## Хаб Раю (між рівнями)

```
┌─────────────────────────────────────────────────────────┐
│                                                          │
│  [Бог-силует]   "Репліка Бога курсивом золотом..."      │
│                                              [Данило]   │
│                                                          │
│  [💡 Апгрейди]      [👻 42/100 Душі]      [Далі →]     │
└─────────────────────────────────────────────────────────┘
```

- **Фон:** небесний, частинки світла, м'яка музика
- **Бог:** яскравий силует без обличчя, позиція ліво
- **Данило:** гібридна форма (ряса + темні елементи), позиція право
- **Репліка Бога:** курсив, золотий колір, автоховається через 8 сек
- **Кнопки знизу:** Апгрейди (ліво) • Душі (центр) • Далі → (право)
- Хаб можна пропустити кнопкою "Пропустити"

```
┌─────────────────────────────────────────────────────────┐
│          РІВЕНЬ ПРОЙДЕНО           ★ ★ ☆ (top-right)   │
│           Коло 1 • Рівень 3                             │
│                                                          │

│    💀 Смерті:  0                                        │
│    🕐 Час:     2:34                                     │
│    📈 Гріх:    ████░░░░  12%  (+2%)                     │
│                                                          │
│    💡 +15 Світла                                        │
│                                                          │
│         [Меню]              [Далі →]                    │
└─────────────────────────────────────────────────────────┘
```

**Зірки:**
| Зірки | Умова |
|-------|-------|
| ★★★ | всі душі + 0 смертей |
| ★★☆ | всі душі + ≤2 смерті |
| ★☆☆ | решта варіантів |

**Sin Delta:** показує зміну гріху за рівень (+/− %)

## Колекція Душ

```
┌─────────────────────────────────────────────────────────┐
│   Врятовані Душі            42 / 100    ✦ 3 / 20       │
│                                                          │
│  ┌──┐ ┌──┐ ┌──┐ ┌──┐ ┌──┐  ← Коло 1                   │
│  │Марія│Остап│Ганна│?│?│                                 │
│  └──┘ └──┘ └──┘ └──┘ └──┘                              │
│                                                          │
│  ┌──┐ ┌──┐ ← Коло 2                                    │
│  │  │ │?│                                               │
│                                                          │
│  [ Вибрана душа: Марія, 7 р. — епітафія тут... ]       │
└─────────────────────────────────────────────────────────┘
```

- Доступна з: головне меню, пауза, екран завершення рівня
- Душі згруповані по колах
- Врятована: показує ім'я + рамку (срібна / золота для прихованих)
- Не знайдена: `?` в рамці (завжди видно що є)
- При виборі внизу: ім'я, вік, епітафія, тип душі
- Приховані `✦` відображаються завжди — з `?` поки не знайдені

## Смерть / Respawn

- **Екран смерті:** fade to black, заголовок мовою гри
- **Respawn:** гравець повертається на останній чекпоінт, душі зберігаються
- **Штраф:** невеликий % гріху за смерть (конфіг: `death_system_config.json`)

## Система смерті

> Джерело: `death_system_config.json`

**Причини смерті:**
| Причина | Миттєва? |
|---------|----------|
| Удари ворогів (HP → 0) | Ні |
| Лава / отрута | Так |
| Падіння за межі | Так |
| Потоплення (лічильник повітря) | Ні |

**Послідовність:**
1. Анімація падіння
2. Затемнення екрану (0.6 сек)
3. +5% гріху
4. Душа повертається на початкове місце (або залишається — з апгрейдом)
5. Лічильник смертей +1
6. Перевірка ліміту → respawn

**Ліміти смертей (soft):**
| Тип рівня | Ліміт |
|-----------|-------|
| vertical | 3 |
| void | 5 |
| boss | без ліміту |

*Soft limit:* при досягненні ліміту не провал — автоматично +1 спроба за ціну +5% гріху.

**Апгрейд "Прощення":** раз на рівень не дає вмерти при 0 HP — залишається 1 HP, без штрафу гріху.

## Камера

> Джерело: `camera_config.json`

| Параметр | Значення |
|----------|---------|
| Тип | follow_with_lookahead |
| Lookahead горизонталь | 120 px перед обличчям |
| Затримка при зміні напрямку | 0.3 сек (уникає різких стрибків) |
| Smoothing speed | 5.0 |
| Вертикальний deadzone | 80 px (камера рухається тільки якщо гравець виходить за межі) |
| При падінні | дивиться вниз на 60 px |
| Zoom звичайний | 1.0× |
| Zoom на void рівнях | 0.8× (більший огляд) |
| Межі | камера не виходить за межі рівня |

**Реалізація:** PhantomCameraManager (плагін вже підключений в `project.godot`).
